# 🚀 Things I've Built

## 🤖 AI Resume Matcher

> An AI-powered Chrome Extension that helps analyze resumes against job descriptions.

**Built with**

`React.js` `Node.js` `Express.js` `Groq AI` `Manifest V3`

### What it does

* 📄 Parses resumes and job descriptions
* 🤖 Uses LLMs for intelligent resume analysis
* 🎯 Provides ATS compatibility insights
* 🔍 Performs keyword and skill matching
* 💡 Generates improvement recommendations
* 📊 Provides interview probability insights
* 📑 Generates PDF reports
* 🧩 Uses Chrome Runtime Messaging & Storage APIs
* ⚙️ Uses background service workers
* ☁️ Backend deployed on Railway

🔗 **[View Project](https://github.com/Varshith-kummarikunta/AI-Resume-Matcher-Chrome-Extension)**
